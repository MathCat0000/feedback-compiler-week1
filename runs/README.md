# Published evidence runs

The working directory retains every local run, including intermediate and private runs. The public repository includes only three representative artifacts:

- the final 30-case controlled run;
- the final 8-case heterogeneous run;
- the final 8-case attributed public-data input-pack run.

Earlier runs remain available locally for audit and comparison but are intentionally not published as repository history. Private runs are ignored and must never be committed.
